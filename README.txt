MealPlan v1.0 - doar interfața publică
1. Creează un repository NOU mealplan pe GitHub.
2. Încarcă în rădăcină index.html, service-worker.js, manifest.webmanifest, icon.svg, icon-192.png și icon-512.png.
3. Settings > Pages > Deploy from branch > main / root.
4. Deschide adresa GitHub Pages și instalează aplicația pe telefon.
5. În Setări > Importă rețetele personale, selectează retete-personale.json din arhiva PRIVATĂ.
IMPORTANT: Nu încărca retete-personale.json pe GitHub; este un fișier privat ce conține extrase din cărți protejate prin drepturi de autor.
Extracția automată are lacune. Verifică informațiile în PDF înainte de utilizare.
